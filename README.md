# 도담이 포도송이 루틴 V5.0 — 포도은행

## 해결된 문제
오늘 할 일을 삭제하거나 이름·점수를 바꿔도, 이미 완료해서 받은 포인트가 총합에서 사라지지 않습니다.

## 작동 방식
- 루틴을 완료한 시점의 이름과 점수를 거래내역에 영구 저장
- 루틴 삭제와 과거 포인트 기록을 분리
- 마을 상품 교환은 마이너스 거래로 기록
- 엄마 직접 지급·차감도 거래내역에 기록
- 엄마모드 아래에 `포도은행 거래내역` 표시

## 주의
V5 설치 전에 이미 삭제되어 점수 정보까지 없어진 할 일은 자동으로 점수를 알아낼 수 없습니다.
그 점수만 엄마모드의 `포인트 직접 지급`에서 한 번 보정하면, 이후부터는 삭제해도 유지됩니다.
